# Catalog visibility is default-deny, gated by Casbin roles

Every prior RBAC decision ([#13](https://github.com/ditwrd/pavedway/issues/13), [ADR 0004](0004-casbin-two-tier-rbac.md)) scoped what a role *edits*, never what it *sees* — no ticket had addressed catalog read visibility until [Design basic catalog search](https://github.com/ditwrd/pavedway/issues/16) forced the question, since search is the first read path with no "owner" fallback to fall back on.

We decided: catalog visibility is **default-deny**. An entity is visible to a caller only via an explicit Viewer(+) grant — a Team-scoped role on its owning Team, an Org-scoped role, or a permission-set-derived cross-team grant (ADR 0004's building blocks). Every Team auto-seeds a default Viewer role for its own members at Team creation, so joining a team is sufficient to see that team's own resources without a separate manual grant; cross-team visibility still requires an explicit grant. An Org-scoped Admin role implicitly bypasses Team-level view restrictions (sees everything org-wide) — standard superadmin semantics. Search resolves visibility efficiently by precomputing the caller's visible Team-id set from Casbin once per request, then filtering with a single SQL `WHERE owning_team_id IN (...)`, not a per-row `Enforce()` call; every future read path (not just search) should follow the same precompute-then-filter pattern.

This is hard to reverse (flipping the default later means auditing or backfilling every existing entity's grants, and every read path built against one default must be revisited if the other is chosen instead), surprising without context (most developer catalogs, including Backstage itself, are openly browsable org-wide by default — locking pavedway to default-deny is a deliberate deviation from that expectation), and a real trade-off (default-deny is a genuine access boundary consistent with ADR 0004's Casbin investment, at the cost of onboarding friction: every team's auto-seeded default Viewer role must be wired correctly or its members see nothing).
